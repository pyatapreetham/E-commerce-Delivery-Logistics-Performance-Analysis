## Data Cleaning Using Power Query

Cleaned and transformed the (DataCo Supply Chain dataset which name changes to ecom logistics cleaned dataset) using Power Query Editor to prepare it for analysis and Power BI reporting.

**Key steps performed:**
- Reviewed data quality and identified missing or unnecessary columns.
- Removed empty, constant, and masked columns.
- Corrected data types for dates, numeric fields, and IDs.
- Cleaned text fields by trimming extra spaces and standardizing country names.
- Prepared ZIP codes to preserve leading zeros.
- Created calculated columns for order year, processing days, delivery delays, late deliveries, cancellations, and KPI eligibility.
- Retained all order-item rows for further analysis.

**Tools:** Power BI, Power Query Editor, CSV
